# Support

FastAuth is a community-maintained beta project.

- Use [GitHub Discussions](https://github.com/bhargavandhe/fastauth/discussions)
  for usage questions, design discussions, and integration help.
- Use [GitHub Issues](https://github.com/bhargavandhe/fastauth/issues) for
  reproducible bugs and scoped feature proposals.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities. Never disclose a
  suspected vulnerability in a public issue or discussion.

Support is best effort and has no response-time guarantee. Include your FastAuth
version, Python version, database adapter, minimal configuration, and a small
reproduction. Remove credentials, tokens, connection strings, and personal data.
